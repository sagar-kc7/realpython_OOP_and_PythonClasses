# realpython_OOP_and_PythonClasses

A small collection of Jupyter notebooks based on Real Python tutorials, focused on learning **Object-Oriented Programming (OOP)** and **Python classes**.

## Contents

- `realpython_OOP.ipynb` — Notes and runnable examples from Real Python’s *Object-Oriented Programming (OOP) in Python* article.
- `realpython_Python_Classes.ipynb` — Notes and runnable examples from Real Python’s *Python Classes: The Power of Object-Oriented Programming* article.

## How to use

1. Clone this repository:
   ```bash
   git clone https://github.com/sagar-kc7/realpython_OOP_and_PythonClasses.git
   cd realpython_OOP_and_PythonClasses
   ```
2. Open the notebooks in Jupyter Lab / Jupyter Notebook, or in Google Colab.
